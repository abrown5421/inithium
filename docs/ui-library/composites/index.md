# Composites

Composites combine components into larger pieces, for example a modal built from Containers, Text and buttons. Each gets a page here when it is built. None exist yet; the planned ones include modal, alert, drawer, pagination, breadcrumbs, tabs, an auto-incrementing list and a colour picker.
