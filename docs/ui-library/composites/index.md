# Composites

Composites combine components into larger pieces, for example a modal built from Containers, Text and buttons. They live in `@inithium/shared-ui-composites` and may use components, never layouts.

| Composite | Use it for |
| --- | --- |
| [Modal](modal.md) | Dialogs over the page, openable from anywhere through Redux |

Still to come: alert, drawer, pagination, breadcrumbs, tabs, an auto-incrementing list and a colour picker.
